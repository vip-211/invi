# Nitin & Khushi — Wedding Invitation Website

Static site (HTML/CSS/JS). No build step.

## Edit details
Open `script.js` — everything is in the `CONFIG` block at the top
(timings, venue name, map search text, WhatsApp number).
Names/parents text are in `index.html`.

## Deploy on Vercel
1. Easiest: go to vercel.com/new → drag & drop this folder (or run `npx vercel --prod` inside it).
2. Or push to GitHub → Import project in Vercel → Framework: "Other" → Deploy.
